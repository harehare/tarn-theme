## Installation

**Double-click** `tarn.itermcolors` to import it automatically, or:

1. Open **iTerm2 → Preferences** (`Cmd+,`)
2. Go to **Profiles → Colors**
3. Click **Color Presets…** → **Import…**
4. Select `tarn.itermcolors`
5. Choose **Tarn** from the Color Presets dropdown
