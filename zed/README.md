# Tarn Theme for Zed

A dark theme for [Zed](https://zed.dev), inspired by the stillness of a high-altitude glacial lake.

## Installation

Copy `tarn.json` to your Zed themes directory:

```bash
cp tarn.json ~/.config/zed/themes/
```

Then open Zed, press `Ctrl+Shift+P` / `Cmd+Shift+P` and run:

```
theme selector: toggle
```

Select **Tarn** from the list.
